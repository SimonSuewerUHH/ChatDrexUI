# DIAMOnD Agent

## Overview
DIAMOnD (Disease Module Detection) is a computational tool that identifies disease-associated gene clusters by expanding biological networks around known seed genes.

## Functionality
- Identifies disease-associated gene clusters
- Expands biological networks around known seed genes
- Analyzes protein-protein interaction networks
- Discovers disease modules and pathways

## Usage
The DIAMOnD agent is used for:
1. Disease gene prioritization
2. Network-based disease module identification
3. Biological pathway analysis
4. Gene-disease association studies

## Input Requirements
- Seed genes (known disease-associated genes)
- Protein-protein interaction network
- Disease context or phenotype information

## Output
- Ranked list of candidate disease genes
- Disease module visualization
- Network expansion results
- Statistical significance scores
