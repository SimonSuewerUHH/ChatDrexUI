Multi Agent System

Network-based drug repurposing, conversationally enabled.

ChatDRex is a conversation-driven, multi-agent system for network medicine–based drug repurposing. Built on the integrated systems medicine knowledge graph NeDRex, it provides natural-language access to large-scale biomedical data and orchestrates specialized bioinformatics agents for network analysis, candidate prioritization, functional validation, and literature mining.

By coordinating task-specific agents for query routing, algorithm execution, result visualization, and scientific interpretation—supported by a reasoning module for transparency and hallucination detection—ChatDRex enables clinicians and researchers to perform complex in silico analyses without programming expertise. This democratizes access to bioinformatics, supports hypothesis generation, and accelerates translational research toward personalized therapies.
