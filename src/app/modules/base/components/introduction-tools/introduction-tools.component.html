ChatDRex Agents

  • Summary Agent
    Provides concise overviews and synthesizes information from various sources to deliver clear and informative summaries.
  • Planning Agent
    Acts as the central orchestrator, analyzing user queries and directing tasks to the appropriate specialized agents for efficient processing.
  • DIGEST Agent
    Ensures functional coherence by facilitating gene set analysis and enrichment, enabling exploration of biological functions and pathways.
  • Network Agent
    Handles biological network analyses with specialized tools:
    • DIAMOnD: Identifies disease-associated gene modules by expanding networks around seed genes.
    • TrustRank: Assesses reliability of gene associations through trust propagation within networks.
    • Closeness: Measures network proximity to determine gene relevance and interactions.
  • Knowledge Graph Agent
    Manages complex queries by constructing and executing knowledge graph queries, integrating diverse biomedical data sources.
  • Research Agent
    Conducts literature mining using advanced search strategies to retrieve and refine relevant scientific publications.
  • Finalize Agent
    Synthesizes outputs from all agents into structured, well-formatted responses, incorporating guardrails to ensure accuracy and reliability.

ChatDRex’s multi-agent framework delivers precise, coherent, and reliable biomedical insights by leveraging specialized agents tailored for summarization, planning, functional analysis, network exploration, knowledge graph querying, literature mining, and final synthesis. This integrated approach supports advanced biomedical research and network-based drug repurposing with enhanced transparency and accuracy.
