ChatDRex: Multi-Agent Tool Overview

  • Start Node: Intelligent Orchestrator
    Acts as the system's central hub, analyzing user input and directing it to the appropriate agent. By leveraging LLMs, it ensures that each query is processed by the most relevant agent, enhancing task specialization and optimizing system performance.
  • LLM Node: Conversational Engine
    Handles general inquiries, explanations, and discussions related to tool outputs. It operates independently of external tools, ensuring robust and insightful responses while acting as a fallback mechanism for unhandled queries.
  • DIGEST Node: Functional Enrichment Analysis
    Facilitates gene set analysis by interfacing with DIGEST, enabling users to explore biological networks such as Gene Ontology (GO) and KEGG. Presents results both textually and graphically for intuitive interpretation.
  • Network Node: Biological Network Exploration
    Manages queries related to gene interactions and network-based analyses using several specialized tools:
    • NeDRexDB: Generates Cypher queries to extract data from the NeDRex database.
    • DIAMOnD: Identifies disease-associated gene clusters by expanding biological networks around known seed genes.
    • TrustRank: Evaluates gene association reliability by propagating trust scores within the network.
  • Research Node: Literature Mining
    Uses Semantic Scholar to retrieve relevant scientific literature. An LLM-driven task decomposition method splits queries into multiple refined searches, improving result accuracy and relevance.
  • Generate Node: Structured Response Synthesis
    Compiles information from processing agents into structured, Markdown-formatted responses. Ensures academic accuracy by citing sources and adhering to scientific reporting standards.
  • Grading Node: Validation & Quality Control
    Implements a two-step process to mitigate LLM hallucinations:
    • Hallucination Chain: Cross-checks generated content against validated sources to eliminate inaccuracies.
    • Grading Chain: Assesses response relevance, clarity, and correctness, iteratively refining outputs for high-quality results.

ChatDRex’s multi-agent approach ensures precise, transparent, and bias-mitigated biomedical insights. By integrating validated data sources and state-of-the-art computational methods, it provides a conversational platform tailored for network-based drug repurposing and advanced biomedical research.
